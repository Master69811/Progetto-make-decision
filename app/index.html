📱 Altre viste

          

            Questa pagina (app/index.html) è l'app principale: la sidebar diventa barra in basso sotto gli 860px, quindi funziona anche da telefono.

            Per la postazione fissa in ufficio c'è app/pc.html (stesso design, solo desktop); per liste senza trascinamento c'è app/classic.html — stessa logica, stesso registro decisioni.

            Se pubblichi il repo con GitHub Pages, aprendo le pagine dallo stesso dominio i dati restano separati per pagina (ogni file ha il proprio localStorage): usa il backup JSON per portarli da una vista all'altra.
          

        

        

          
🔗 Come funziona con Claude

          

            1. Registra qui criticità, KPI e agenda durante la giornata.

            2. In Plancia, tocca il comando che ti serve: ottieni il prompt con lo stato già dentro.

            3. Incollalo in una chat del repo Progetto-make-decision: la Decision Engine risponde con decisione, piano e refactoring.

            4. Riporta qui la decisione presa e spunta le attività fatte.
