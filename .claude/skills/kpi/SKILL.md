# Protocollo /kpi

1. Leggi la tabella KPI in `contesto/profilo.md` (indicatori, target, frequenza).
2. Chiedi i valori attuali, se non forniti (anche incollati grezzi da ERP/MES/Excel).
3. Per ogni KPI produci una riga: **valore vs target → stato (OK / attenzione / fuori target) → causa probabile → azione correttiva con responsabile**.
4. Chiudi con:
   - **I 3 interventi della settimana** — le sole azioni che spostano davvero gli indicatori, in ordine di impatto.
   - **Refactoring** — se un KPI è fuori target per la seconda volta di fila, proponi una modifica strutturale al processo, non un'altra azione tampone.
5. Se i target in `contesto/profilo.md` risultano superati o irrealistici, proponi di aggiornare il file.

Niente analisi accademiche: ogni riga deve finire con un'azione e un nome.
